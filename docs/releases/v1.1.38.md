## ✨ Novedades
- 🎵 **Tus audios ahora son MP3 de verdad** — Al descargar solo el audio, el archivo sale en MP3 reproducible en cualquier reproductor, con el título, el artista y la carátula dentro del propio archivo.
- 🖼️ **Los posts de fotos de TikTok ya se descargan** — Los enlaces de fotos con música ofrecen lo que de verdad tienen: la música para guardarla como MP3 y la imagen del post. Ya no aparece una opción de vídeo que no existe.

## 🚀 Mejoras
- ⚡ **La reproducción en Explorer empieza antes** — La dirección del vídeo que vas a reproducir se busca mientras se cierra el anterior, así el primer fotograma llega antes y se evita tocar Play dos veces.
- 📊 **Análisis de enlaces más completo y más rápido** — El análisis devuelve todas las calidades y pistas de audio disponibles (en algunos vídeos solo aparecía una) y responde antes; repetir el mismo enlace es instantáneo.
- 💿 **El reproductor enseña la carátula del archivo** — Al reproducir una descarga, el reproductor y la notificación muestran el título, el artista y la carátula que lleva dentro el propio archivo, aunque falten los datos de la descarga.
- ⚙️ **Ajustes, ordenado por bloques** — Los ajustes están agrupados en bloques con las descargas primero y cada grupo con su título, para encontrar cada opción de un vistazo.

## 🛠️ Correcciones
- 🎬 **Los vídeos sin audio ya se descargan con sonido** — Las calidades que venían sin pista de audio se unen con la mejor pista disponible antes de guardarse, así el archivo nunca acaba mudo.
- ✨ **Se acabó el destello blanco al minimizar el vídeo** — Al minimizar el vídeo o redimensionar la ventana flotante ya no aparece un fogonazo blanco: la ventana se pinta en negro mientras se recoloca.

## ✨ What's new
- 🎵 **Your audio downloads are real MP3 files now** — When you download only the audio, the file comes out as a playable MP3 in any player, with the title, the artist and the cover inside the file itself.
- 🖼️ **TikTok photo posts can be downloaded now** — Photo links with music offer what they really have: the music to save as an MP3 and the image of the post. A video option that does not exist no longer shows up.

## 🚀 Improvements
- ⚡ **Explorer playback starts sooner** — The address of the video you are about to play is looked up while the previous one is closing, so the first frame arrives sooner and there is no need to tap Play twice.
- 📊 **Link analysis is more complete and faster** — The analysis returns every available quality and audio track (on some videos only one used to show up) and answers sooner; repeating the same link is instant.
- 💿 **The player shows the cover inside the file** — When you play a download, the player and the notification show the title, the artist and the cover the file itself carries, even if the download details are missing.
- ⚙️ **Settings, ordered in blocks** — Settings are grouped in blocks with downloads first and a title for each group, so every option is easy to find at a glance.

## 🛠️ Fixes
- 🎬 **Videos without audio download with sound now** — Qualities that came without an audio track are joined with the best available track before saving, so the file never ends up muted.
- ✨ **No more white flash when minimising the video** — Minimising the video or resizing the floating window no longer shows a white flash: the window is painted black while it is being resized.
