## ✨ Novedades
- 🔄 **La actualización ya se instala** — Al pulsar «Actualizar ahora» la app abría una pantalla de ajustes que no existe en todos los móviles, así que la instalación no llegaba a empezar y solo se veía un error técnico. Ahora abre la pantalla correcta de «instalar apps desconocidas» y, al volver con el permiso concedido, continúa la instalación con el archivo que ya había descargado, sin volver a bajarlo.
- 🔢 **La versión avanza** — Esta entrega es la 1.1.43, con su propio número de compilación (55), no un parche que reutiliza el nombre de la 1.1.42.

## ⚡ Mejoras
- ▶️ **Reproducción sin depender del servidor** — Cuando el servidor no puede entregar el enlace del vídeo, la app usa el manifiesto del propio teléfono, así que el primer intento reproduce en lugar de pedir reintentar.
- 📚 **La biblioteca abre en Android 11 y 12** — Se pide el permiso que corresponde a cada versión y la lista de archivos carga de verdad.
- 🖼️ **Miniaturas que no se quedan en gris** — Si la miniatura firmada no existe, se usa la pública del mismo vídeo.

## 🛠️ Correcciones
- 🔎 **Los errores de análisis se explican** — El aviso distingue un enlace inválido, una fuente que rechaza la petición o un fallo del servidor, y se puede cerrar.

## ✨ New
- 🔄 **The update installs now** — Tapping "Update now" opened a settings screen that does not exist on every phone, so the installation never started and only a technical error was shown. It now opens the real "install unknown apps" screen and, when you come back with the permission granted, it continues with the file it already downloaded instead of downloading it again.
- 🔢 **The version moves forward** — This release is 1.1.43, with its own build number (55), not a patch reusing the 1.1.42 name.

## ⚡ Improvements
- ▶️ **Playback without depending on the server** — When the server cannot hand out the video link, the app uses the phone's own manifest, so the first attempt plays instead of asking for a retry.
- 📚 **The library opens on Android 11 and 12** — It asks for the permission each version actually has and the file list really loads.
- 🖼️ **Thumbnails no longer stay grey** — If the signed thumbnail does not exist, the public one of the same video is used.

## 🛠️ Fixes
- 🔎 **Analysis errors explain themselves** — The notice tells an invalid link apart from a source refusing the request or a server failure, and can be dismissed.
